DRESS UP GAME

Pastina Dress Up!

JavaScript · HTML · CSS · Procreate

A pixel art dress-up game starring my shih-tzu, Pastina. Built as a self-taught JavaScript project — all custom artwork made by me in Procreate.

My first time touching any of these languages. CSS gave me the most trouble, which I did not see coming as a UX/UI designer. Next up: more outfit options, and a better way to pick them that scales as the list grows.

RAIL SHOOTER GAME

Bird Feeder

GameMaker · GML · Procreate

A rail shooter where you play as an elderly woman dodging bird poop while feeding birds in the park. Title and end screen art made by me in Procreate; additional artwork sourced and edited from the Cleveland Museum of Art.

Press C for credits, I for instructions, and S to start.
